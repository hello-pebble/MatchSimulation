## 2. Short Polling 비용 실측 (2026-08-01, 3초 간격 10회 / 중간에 1건 전송)

| 회차 | 새 메시지 | 응답 시간 |
| :--- | :--- | :--- |
| 1~5 | 0건 (빈 응답) | 0.010~0.011s |
| 6 | **1건 수신** (전송 직후 폴링) | 0.011s |
| 7~10 | 0건 (빈 응답) | 0.010~0.011s |

- **빈 응답 비율 90%** (10회 중 9회) — 대화가 없어도 요청은 계속 발생
- 메시지 전달 지연: 최대 **폴링 주기(3초)** — 전송 시점과 다음 폴링 사이만큼 늦는다
- 주기를 줄이면 지연은 줄지만 빈 요청이 비례 증가 → **Long Polling(5-3)의 도입 근거**
